# 课表 Lite（astrbot_plugin_schedule_lite）

[![tests](https://github.com/suiren0219/astrbot_plugin_schedule_lite/actions/workflows/tests.yml/badge.svg)](https://github.com/suiren0219/astrbot_plugin_schedule_lite/actions/workflows/tests.yml)

BLBot 式课表功能的 AstrBot 独立实现。重点在**导入**：把不同课表软件导出的数据统一成
「第几周 + 星期几 + 起止时间」，再做去重合并、补全作息和异常提示。

## 功能

- 多来源导入：Nexio 课程表分享口令/JSON/ICS、小爱课程表分享链接、WakeUp 课程表口令/备份、iCalendar(.ics)、拾光课程表 JSON、通用 JSON/CSV
- 广泛的 ICS 兼容：Nexio 课表、拾光课程表、小爱伴侣、WakeUp 等多数课表 App 都能导出
  `.ics`，导出文件或分享链接直接导入即可；课程名、教师、地点、周次会从标题/描述里尽量提取
- WebUI 控制台：AstrBot 插件页里管理课表数据（增删改）、节假日缓存和全部运行设置；支持在后台粘贴口令/链接/JSON/ICS 或文件直接导入；支持浅色、深色、跟随系统三态主题，并跟随 AstrBot 后台主题变化
- 图片输出：帮助手册渲染成 Markdown 长图，按合并转发一次发出；「群友在上什么课」是
  状态卡片图片，人多自动分页（未装 Pillow 或找不到中文字体时自动退回文字）
- 导入归一化：单双周、分段周次、`1-16/2` 步长、`1-2节` 节次、`8点30` 等时间写法
- 自动合并：同一门课同名、同天、同时间、同地点被拆成多条时合并周次
- 作息兜底：只有节次没有时间时使用面板配置的默认作息，并给出提示
- 课表查询：今天/明天/周几/日期，支持 @群友
- 群友在上什么课、今日/本周/学期课程时长榜；请假/翘课优先，无课排最后，人多自动隐藏无课
- 学生自助：请假/销假、按日期调课（可互换）、查询节假日和补班、重要日期倒计时
- 国务院节假日/调休：本地缓存，放假跳过课程，补班按对应星期上课
- 定时节目：明日早八提醒（可艾特）、晚间满课榜、周五/假日前累计课时长榜，渲染成状态卡片图片（无字体退回文本），每个群每天最多一次
- 上课提醒、课程备注、翘课状态、个人作息修改
- 本地 JSON 存储，原子写入；教师和上课地点默认不保存
- 性能：按星期建立课程索引，状态查询走分钟级本地缓存，不依赖外部接口
- 状态匹配优化：按「用户 + 分钟」缓存结果，多个群查询同一批人时只算一次；
  当天课程快照缓存，写入/请假/调课/节假日刷新时自动失效；下一节课用二分查找

## 安装

1. 把整个 `astrbot_plugin_schedule_lite` 目录放进 AstrBot 的 `data/plugins/`
2. 在面板启用插件，按需修改配置
3. 依赖：AstrBot ≥ 4.10.4（配置页的作息列表用到 `template_list`）、`aiohttp`、`Pillow`；Windows 上建议装 `tzdata` 以正确解析其他时区（缺省仍可用 UTC+8）
4. 图片功能需要中文字体。Windows/macOS 会自动找到系统字体；Linux 服务器请安装
   `fonts-noto-cjk` 或在配置里填 `font_path`

## 指令

| 指令 | 说明 |
| --- | --- |
| `/课表` | 查看自己今天的课表 |
| `/课表 明天`、`/课表 周三`、`/课表 2026/9/1` | 查看指定日期 |
| `/课表 @张三 明天` | 查看群友课表（需对方在本群用过课表） |
| `/课表 在上` | 群友现在在上什么课（私聊则看自己） |
| `/课表 排行 [今日\|本周\|本月\|学期] [全部]` | 课程时长榜，默认本周前九 |
| `/课表 导入 <链接/口令/JSON/文件>` | 导入课表，自动识别格式；也支持引用含文件/链接的消息 |
| `/课表 删除` | 删除自己的课表 |
| `/课表 提醒 [分钟\|关]` | 私聊订阅上课提醒，默认 15 分钟 |
| `/课表 备注 <课程> [备注]` | 设置/清除课程备注，课程名支持部分匹配 |
| `/课表 翘课` | 切换今日翘课状态 |
| `/课表 请假 [日期\|范围] [原因]` | 登记请假，如 `9/10`、`9/10-9/12 病假` |
| `/课表 销假 [日期]` | 取消某天或今天的请假 |
| `/课表 调课 [课程] A B [互换]` | 把 A 的课调到 B；`撤销 [日期]` 撤销，`清空` 清除 |
| `/课表 调休 [日期] [周几\|清]` | 查看节假日（图片卡片），或手动指定补班 |
| `/课表 倒计时` | 重要日期倒计时（四六级等，控制台维护） |
| `/课表 作息 [1 08:00-08:45 …]` | 查看/修改个人作息 |
| `/课表 学期 2026-09-07` | 修正第 1 周周一（CSV 等没带开学日期时用） |
| `/课表 导出` | 输出本插件的通用 JSON |
| `/课表 帮助` | 使用手册（合并转发图片）；`/课表 帮助 文本` 只看文字 |

也支持 `/课表导入 …`、`/课表排行 …` 这种直接写法。

## 导入方式

### 小爱课程表

1. 在小爱课程表 App 里导入或手动录入课表
2. 课程表设置 → 分享课表 → 复制分享链接
3. `/课表 导入 <完整链接>`

链接里的 token 包含 `userId / deviceId / ctId`，插件据此请求小爱课表接口。
接口属于小米，可能随时调整；失败时会给出具体原因。

### WakeUp 课程表

- 在线：分享 → 在线分享课表 → 复制口令（含「」也可以），`/课表 导入 <口令>`
- 本地：分享 → 导出为备份文件，把 `.wakeup_schedule` 文件直接发给机器人

### iCalendar（推荐，兼容最多）

- `/课表 导入 https://.../xxx.ics`，或把 `.ics` 文件发给机器人
- 适用于 Nexio 课表、拾光课程表、小爱伴侣、WakeUp 以及大多数第三方课表 App 的
  「导出日历 / 导出 ICS」功能；不需要登录接口，兼容性最稳
- 支持 `DTSTART/DTEND`、`TZID`、UTC、浮动时间、`DURATION`、`RRULE`
  （WEEKLY/DAILY/MONTHLY/YEARLY、`INTERVAL`/`BYDAY`/`UNTIL`/`COUNT`）、
  `EXDATE`、`RDATE`、`RECURRENCE-ID` 单次改期，以及 Windows 风格 TZID
- 会从 `SUMMARY`、`DESCRIPTION`、`LOCATION` 里提取课程名、教师、教室和周次；
  也认识「周次：1-16周(单)」「教师：张三」这类中文伪属性
- 支持一个事件写多个上课日、按标题里的周次过滤重复规则、缺少 `RRULE` 但写了
  周次的单事件按周展开
- 全天日程（没有具体时间）会跳过并提示

### Nexio 课程表

Nexio 有三种导入方式，任选一种：

- **分享口令**（推荐）：App 里分享课表 → 生成口令，`/课表 导入 示例课表已上线`；
  口令 30 分钟内有效，过期需要重新生成
- **ICS**：分享 → 导出 `.ics`，把文件发给机器人
- **JSON**：分享 → 导出课表 JSON，发文件或粘贴内容

Nexio 的 ICS 常把教师写在 `LOCATION` 末尾（`A101 张老师,李老师`），插件会自动
拆成教室和教师；JSON 里的 `selectedWeeks`、单双周、自定义时间、三段时间表都会保留。

### 拾光课程表

App 里导出单表 JSON，直接发文件或粘贴内容。字段以 App 源码
`CourseImportExport.kt` 为准（`name/position/day/startSection/endSection/weeks`、
`timeSlots`、`config.semesterStartDate`）。整库备份（`databasePayload`）暂不支持。

### 通用 JSON / CSV

JSON 支持顶层是对象或数组，字段名兼容中英文：

```json
{
  "name": "我的课表",
  "term_start": "2026-09-07",
  "total_weeks": 20,
  "courses": [
    {"name": "高等数学", "day": 1, "start": "08:00", "end": "09:40",
     "weeks": "1-16", "location": "A101"}
  ]
}
```

CSV 用表头识别列，至少需要课程、星期、开始、结束、周次；也接受固定列序
`课程,星期,开始,结束,周次,地点,教师`。

## 图片输出

### 帮助长图

`/课表 帮助` 把 `docs/help.md` 排版成几张长图，放在一条合并转发消息里发送，
避免刷屏。Markdown 源文件和渲染出的 PNG 都会留存在插件数据目录：

```
data/plugin_data/astrbot_plugin_schedule_lite/help/
├── help.md           # 本地留存的手册
└── help-*.png        # 按内容哈希缓存的图片，改文档会自动重渲染
```

平台不支持合并转发时会逐张发送；生成失败自动退回文字版。`/课表 帮助 文本`
永远只发文字。

### 群友在上什么课

`/课表 在上` 在群里发送状态卡片：每人一行，带头像首字母、昵称、状态色块
（翘课/请假 / 正在上课 / 即将上课 / 有空 / 无课程）、当前课程和教室/时间。
排序依次为：翘课/请假 → 进行中/分身中 → 下一节 → 已结束 → 无课程；
超过 `everyone_hide_idle_over`（默认 12 人）时隐藏无课同学，并在图片底部注明。
默认每页 8 人，人多自动分页，每页一张图。图片缓存在 `cache/everyone/`，
只统计在本群用过课表的人。

状态计算全部基于本地缓存：每份课表维护按星期索引的课程表，状态结果按
「用户 + 分钟」缓存，当天课程快照也会复用，多个群查同一批人时不会重复计算；
下一节课用二分查找。写盘、请假、调课、节假日刷新都会自动清空相关缓存。

## WebUI 控制台

在 AstrBot 的插件页打开「课表控制台」（`pages/dashboard/`），可以：

- **导入**：粘贴口令/链接/JSON/ICS 或选择文件，填写用户 ID 后由 AstrBot 后台解析入库
- **概览**：绑定人数、课程数、活跃群、今日节假日、群友状态分布
- **数据**：搜索、新增、编辑、删除课表；课程行支持星期、周次、节次或具体时间
- **记录**：直接编辑请假、调课、补班和群绑定；新增调课会由后端生成课程快照
- **调休**：查看本地节假日缓存，按年份手动刷新
- **设置**：隐私开关、分页人数、隐藏无课阈值、满课榜/累计榜、节假日接口、全局补班映射等

页面右上角的主题按钮可以在「跟随系统 → 浅色 → 深色」之间切换，选择会记在
浏览器本地。跟随系统时，如果运行在 AstrBot 插件页内，会优先使用后台当前的
深色/浅色状态；移动端也保留这个按钮。

控制台注册的 API 前缀是 `/astrbot_plugin_schedule_lite/page/`，只在本机
AstrBot 后台内可用；数据写入与聊天指令共用同一份 `timetables.json`。

Miuix 目前只提供 Compose Multiplatform 组件，没有可直接引用的 Web 构建；
控制台按 Miuix / HyperOS 的视觉规范用原生 HTML/CSS 实现，不引入前端构建链，
安装后即可使用。

## 定时节目

- **明日早八推送**：前一晚 `early_time`（默认 21:30）推送明天首节课不晚于
  `early_max_start`（默认 08:00）的同学，`early_at` 开启后逐个 @ 同学；
  节假日自动跳过，30 天内的重要日期会附带
- **今日满课榜**：每天 `showcase_time`（默认 22:30）发送当天课时最长的人，
  `showcase_min_minutes` 控制最低分钟数，`showcase_min_users` 控制最少人数
- **周/月累计榜**：`recap_weekday`（默认周五）或假日前一天的 `recap_time`
  发送本周/本月累计上课时间 Top N，`recap_mode` 选 `week` 或 `month`

只向用过课表的群发送，每个群每天最多一次；发送状态持久化在
`broadcast_state.json`，重启不会重复发送。

## 导入时的数据优化

- 周次：`1-16`、`1~16`、`第1-16周`、`1-16周(单)`、`1-16单周`、`1-8单,10-16双`、`1-16/2`
- 小节：`1-2`、`1,2`、`第1-2节`，配合作息换算成具体时间
- 时间：`8:00`、`08：00`、`0800`、`8点`、`8点30`、`08:00:00`
- 星期：`周一/星期一/礼拜一/MO/Monday/1`；`0` 视为周日
- 同一门课同名、同天、同时间、同地点但周次被拆成多条时自动合并
- 星期或时间异常、缺周次的数据会被跳过，并在导入回执里列出原因
- 课程周次超过声明的总周数时自动放宽，不丢课
- 作息缺失时用配置里的默认作息，并提示

## 安全

从用户给的链接导入时，默认只允许公网 http/https，拒绝 127.0.0.1、局域网和云元数据地址，
并手动跟随重定向、每一跳都重新检查，避免把机器人当作内网代理（SSRF）。确实需要内网导入时打开
`allow_private_network`。

## 隐私

- 课表数据存在插件数据目录 `timetables.json`，不上传任何第三方（导入时只访问你给的链接）
- 任课教师和上课地点**默认都不保存**：导入时直接丢弃，历史数据在插件启动时也会被清除；
  如需显示，在面板打开 `store_teacher` / `store_location` 后重新导入课表
- 群里只能查在**本群**用过课表的人；想允许跨群查询，打开 `allow_cross_group`
- 备注只在私聊查看；上课提醒只走私聊会话
- `/课表 删除` 会永久删除自己的课表、备注和订阅设置

## 已知限制

- 小爱课程表分享功能已被小米长期下线过，链接可能根本打不开；插件仍会尝试按分享链接里的 token 调接口，失败会提示具体原因
- Nexio 分享口令依赖 App 自建的中转服务（固定 IP + 3000 端口），服务变动时会失效；长期使用建议导出 ICS/JSON
- 小爱/WakeUp 的导入都依赖官方接口，接口变动时可能需要更新适配
- WakeUp 的接口固定带 `version: 280` 请求头，上游改版后可能失效
- 拾光只支持单表导入 JSON，不支持整库备份
- iCalendar 只实现常用子集；带 `BYSETPOS` 等复杂规则的日程可能不完整
- 国务院没有公开的节假日 JSON API，插件使用 timor.tech / holiday-cn 的整理数据，
  官方临时调整时以本地缓存刷新为准
- 图片功能依赖 Pillow 和中文字体；两者缺失时会自动退回文字，不影响导入和查询
