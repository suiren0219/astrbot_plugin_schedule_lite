# 课表 Lite 使用手册

把课表软件里的数据变成群聊里的服务：导入课表、看群友现在在上什么课、
比一比谁课时更长、上课前私聊提醒你。

> 发送 `/课表 帮助` 会先列出分类，再发送 `/课表 帮助 导入`、`/课表 帮助 查询`
> 等即可只看对应分类；`/课表 帮助 全部` 查看完整手册。

## 快速开始

1. 在课表 App 里导出 `.ics` 文件，或复制分享口令 / 分享链接
2. 把文件、链接或口令直接发给机器人（文件前加 `/课表 导入` 也行）
3. 发送 `/课表` 查看今天的课

QQ 里文件只能单独成一条消息，所以有两种带文件的方式：

- 文件直接发给机器人即可自动导入（私聊任意文件；群聊只认
  `.ics` / `.json` / `.csv` / `.wakeup_schedule`，避免误导入）
- 想带上说明或再次确认：**先发文件，再引用（回复）那条文件消息**发送
  `/课表 导入`；引用链接 / 口令 / JSON 消息同样有效

支持 Nexio 课表、拾光课程表、WakeUp，以及任何能导出 iCalendar（.ics）的第三方课表。
ICS 是最通用的格式，推荐优先使用。

> 课表 Lite 不会登录校园网或教务系统，也不会直接抓取学校课表；所有课程数据都来自
> 你自己主动发送的导出文件、分享口令或链接。

> 任课教师一律不保存：解析时只用来识别课程，入库前直接丢弃。
> 上课地点可以保存，但默认不在查询、状态和提醒里显示；需要显示时在面板打开
> `show_location`。

## 导入课表

### iCalendar（推荐）

绝大多数课表软件都支持导出 `.ics`：

- 直接把 `.ics` 文件发给机器人
- 或者发送 `.ics` 的下载链接

插件会从课程标题和描述里识别课程名、教室、教师、周次，并自动处理：
单双周、分段周次、停课（EXDATE）、单次调课（RECURRENCE-ID）、时区换算。

即使导出格式不规范也能尽量吃进去，比如：

- 课程名写成 `高等数学@A101`
- 周次写在标题里：`大学英语(1-8周)`、`体育(1-16周 单)`
- 教师 / 地点 / 周次挤在描述的一行里：`教师：张三，地点：A101，周次：1-8周`
- 全角冒号、Windows 时区名、没有 TZID 的浮动时间

### Nexio 课程表

三种方式任选：

- 分享 → 生成分享口令，把口令发给机器人（如 `示例课表已上线`，30 分钟内有效）
- 分享 → 导出 `.ics` 文件，发给机器人
- 分享 → 导出课表 JSON，把文件或 JSON 文本发给机器人

Nexio 的 ICS 会把教师写在教室后面（如 `A101 张老师,李老师`），插件会自动拆成
教室和教师；JSON 里的单双周、指定周次（`selectedWeeks`）、自定义上课时间也会保留。

### 拾光课程表

在 App 里导出“课程表 JSON”，把文件发给机器人即可。
也支持直接粘贴 JSON 内容。

### WakeUp 课程表

两种方式：

- 分享 → 在线分享课表 → 复制口令，发给机器人
- 分享 → 导出备份文件，把 `.wakeup_schedule` 文件发给机器人

### 通用 JSON / CSV

从其他软件整理出来的表格也能导入。JSON 字段中英文都支持，至少需要：
课程名、星期、开始时间、结束时间、周次。

CSV 建议带表头，列名可以是：课程、星期、开始、结束、周次、地点、教师。
没有开学日期时，导入后用 `/课表 学期 2026-09-07` 修正。

## 查看课表

- `/课表` 今天的课表（只看当前半天）
- `/课表 明天` 明天的课表
- `/课表 周三` 最近的周三
- `/课表 下周三` 下周的周三
- `/课表 9/1` 今年 9 月 1 日
- `/课表 2026-09-01` 指定日期
- `/课表 @张三 明天` 查看群友的课表（需要自己先绑定课表）

不带斜杠也可以：`课表明天`、`课表周三`。

查询**今天**时会按半天分段：上午只显示上午的课，下午只显示下午的课。
如果当天的课在上午就全部结束，下午再查会直接告诉你「今天上午的课已经上完」，
而不是把上午的课当成一整天。查其他日期仍然显示全天课程。

未绑定课表时，`/课表 在上`、`/课表 排行` 和查看别人课表都会先引导你完成导入。

## 群友在上什么课

发送 `/课表 在上`，机器人会发一张图片，按状态排序（需要自己先绑定课表）：

- 翘课中 / 请假中：最优先，今天翘课或登记了请假的人
- 进行中：现在正在上的课，剩余多少分钟
- 分身中：同一时间有多门课
- 下一节：接下来要上的课，还有多久开始
- 已结束：今天该半天的课上完了，一共几小时
- 无课程：今天没有课，排在最后

绑定的人太多时，超过阈值（默认 12 人）就不再展示「无课程」的同学，
底部会注明还有多少人被隐藏；人数可以在控制台里调。

默认还会隐藏最近 3 天没有在本群发过言的成员（`everyone_active_days`）。
刚升级、还没有发言记录的成员会先保留，避免列表突然空掉；当前发指令的人始终保留。
把控制台里的「群友活跃天数」设为 0 即可关闭。

如果群里人多，图片会自动分页（默认每页 8 人）；合并转发里可以左右翻看。
当天状态只用机器人本地已缓存的数据计算，不请求外部接口。

## 翘课

- `/课表 翘课` 只标记**当前正在上的那一节课**；如果现在没课，则标记下一节
- 仅这一节生效，课间、其他课程和第二天都不受影响
- 再发一次可取消；被标记的课程不会发送上课提醒

## 请假 / 销假

- `/课表 请假` 登记今天请假
- `/课表 请假 9/10` 登记某天请假
- `/课表 请假 9/10-9/12 病假` 一段范围，可带原因
- `/课表 销假` 取消今天的请假
- `/课表 销假 9/10` 取消某天的请假（范围内整段取消）

请假期间查询课表会标出「请假中」，「群友在上什么课」里也会排在最前面。

## 调课

把某一天的课整体挪到另一天，适合运动会、考试周这类情况：

- `/课表 调课 9/10 9/12` 把 9/10 的课移到 9/12
- `/课表 调课 9/10 9/12 互换` 两天课表互换
- `/课表 调课 高等数学 9/10 9/12` 只挪这一门课
- `/课表 调课 撤销 9/12` 撤销与这天相关的调课，`/课表 调课 撤销` 撤销最近一条
- `/课表 调课 清空` 清除自己的全部调课记录

调课是按日期记录的快照，不影响平时课表；查询、状态和提醒都会跟着走。

## 节假日与调休

插件内置国务院法定节假日/调休数据（默认来自 timor.tech 接口，
失败时退回 holiday-cn），查询时只读本地缓存，由后台任务定时刷新。

- 遇到放假，当天课表会直接显示「放假」，状态和排行也会跳过
- 遇到补班（调休上班），自动按对应星期的课表上课
- `/课表 调休` 查看最近一段时间的节假日安排
- 接口数据没有覆盖到的补班可以手动指定：
  `/课表 调休 9/27 周一`，`/课表 调休 9/27 清` 撤销
- 寒暑假/校历特殊补班可以在控制台设置「全局补班映射」，例如
  `2026-10-10 周四`，一次设置全群生效；个人 `/课表 调休` 优先

## 课程时长榜

- `/课表 排行` 本周榜，默认前九名
- `/课表 排行 今日`
- `/课表 排行 本月`
- `/课表 排行 学期`
- `/课表 排行 本周 全部` 显示所有人

榜单末尾会单独列出**你自己的名次和时长**，即使没进前九也能看到排第几。
只统计在本群用过课表的人，不会把别的群的数据混进来；未绑定课表时先按引导完成导入。

## 定时节目

在控制台里开启后，机器人会在设定时间向用过的群发送：

- **明日早八推送**：前一晚（默认 21:30）点名明天有早八的同学，可开启逐个艾特；
  节假日自动跳过，控制台里维护的四六级等倒计时也会附带

- **今日满课榜**：晚上（默认 22:30）点名当天课时最长的同学，可设置最低课时和最少人数，人不够就不发
- **周/月累计榜**：每周五（或假日前一天）总结本周/本月累计上课时间，默认 Top 5

每个群每天最多发一次，发送状态会记录在本地，重启也不会重复发。
满课榜和累计榜会渲染成图片卡片，没有中文字体时退回文本。

## 假期与重要日期倒计时

发送 `/课表 倒计时` 会先显示最近的法定假期（寒假、国庆等），再列出控制台维护的重要日期。

- 假期日期来自国务院节假日缓存，后台自动刷新，不需要手动填
- 四六级、期末考试等可以在控制台的「重要日期」卡片里补充
- 30 天内的日期会自动附在早八推送里

## WebUI 控制台

在 AstrBot 插件页打开「课表控制台」，可以：

- 导入课表：粘贴口令/链接/JSON/ICS 或选择文件，由 AstrBot 后台解析入库；
  原始文件会完整存档，编辑页可见「源文件」路径
- 查看概览：绑定人数、课程数、活跃群、今日节假日和群友状态分布；
  「现在的状态」按群分开，同一份课表加入多个群时会分别出现在对应群下
- 新增 / 编辑 / 删除课表：直接改课程安排（星期、周次、节次或时间）
- 编辑请假、调课、补班和群绑定；新增调课会自动生成课程快照
- 查看节假日缓存并手动刷新
- 修改插件设置：隐私开关、分页人数、隐藏无课阈值、定时节目时间和阈值等
- 数据备份：一键导出全部课表与重要日期，恢复会整表覆盖
- 右上角切换浅色 / 深色 / 跟随系统主题（移动端也可以切换）

控制台只是本地数据的管理入口，普通同学仍然用聊天指令即可。

## 修正数据

导入数据不可能永远完美，这几条命令可以事后修正：

- `/课表 作息` 查看当前作息
- `/课表 作息 1 08:00-08:45` 修改第 1 节时间，可以一次发多行
- `/课表 学期 2026-09-07` 修正第 1 周周一
- `/课表 备注 编译 带教材` 给课程加备注，课程名支持部分匹配
- `/课表 备注 编译` 清除备注

修改作息后，只给了节次没给具体时间的课程会自动按新作息重算。

## 上课提醒

先私聊机器人，再发送：

- `/课表 提醒 15` 每节课开始前 15 分钟私聊提醒
- `/课表 提醒 5` 提前 5 分钟
- `/课表 提醒 关` 取消提醒

提醒里会带上课程名和时间；只有打开 `show_location` 才会带地点。

## 隐私

- 课表只存在机器人本地，不上传到任何第三方
- 任课教师一律不保存，导入时直接丢弃；历史数据在启动时也会清除
- 上课地点可以保存（`store_location`），但默认不显示；需要时在面板打开 `show_location`
- 课表存在插件数据目录的 `timetables.json`，可以用 `/课表 导出` 查看自己的数据；
  数据不会上传到第三方（导入时只访问你给的链接）
- 群里只能查在本群用过课表的人；跨群查询默认关闭
- 备注只在私聊查看，上课提醒只走私聊
- `/课表 删除` 会永久删除你的课表、备注和订阅

## 常见问题

### 能直接对接学校的教务系统或校园网吗？

不能。课表 Lite 不登录教务系统、不访问校园网，也不抓取成绩或个人信息。
它只解析你主动发送的课表导出文件、分享口令或链接，因此也不需要学校账号密码。
如果你的课表 App 能导出 `.ics`，直接发文件即可。

### 导入后周次不对

多半是数据里没有开学日期。用 `/课表 学期` 设置第 1 周周一即可。

### 课程时间差了一小时

通常是 ICS 里的时区不对。检查插件配置的 `timezone`，默认是 `Asia/Shanghai`。

### 只有节次没有时间

导入时会使用内置默认作息。可以发送 `/课表 作息` 修改自己的作息，
或在控制台的「编辑课表」抽屉里直接编辑这份课表的作息。

### 图片没有发出来

图片依赖 Pillow 和中文字体。Linux 上可以安装 `fonts-noto-cjk`，
或在配置里把 `font_path` 指向一个中文字体文件。没有字体时会自动退回文字版。

### 导出给别人

`/课表 导出` 会输出本插件的通用 JSON，换机器人或换设备后可以重新导入。
导出内容包含课程安排、作息，以及你的请假、调课、补班记录；导入这份 JSON 会
一并恢复。已经绑定过课表的账号再次导入时，会直接用新文件替换旧课表，
旧课表的备注、请假、调课、补班和翘课状态不再保留。
