# 课表 Lite 宣传视频脚本（v1.10 系列）

- 规格：1920×1080 · 30fps · 9 幕 × 7s ≈ 63 秒
- 风格：深色底 + miuix 卡片，真实渲染素材出镜
- 生成：`python docs/promo/make_video.py`（动效版）→ `promo.mp4`
- 动效：MoviePy（github.com/Zulko/moviepy）时间线——卡片从右滑入（ease-out-cubic）、
  徽章/倒计时条回弹弹入（ease-out-back）、文字上滑淡入、幕间交叉淡化；元素全部预渲染成
  透明 PNG 再合成，渲染快且可复现
- 依赖：`pip install moviepy imageio-ffmpeg`（Pillow 已随主插件）
- 无配音，字幕承载信息；B 站/群动态投稿可直接用

## 素材清单

- `render.render_everyone` 深色 30 人混合卡（复用测试样本数据）
- `render.render_grid_card` 深色排行卡（27+你）
- `render.render_day_card` 深色 12 节日卡（进行中/下一节）
- `render.render_grid_card` 深色早八卡（20 人）
- 网页伴侣 `/help` 目录页截图（浏览器 1280×800，存 `assets/web-help.png`）
- 倒计时条（四六级 36 天 / 国庆放假 / 期末周）由 `countdown_pill` 现画
